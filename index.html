Add a rabbit: three prototypes

Each prototype adds a rabbit to the same demo herd with the same steps: basics, breed (purebred or a crossbred mix totalling 100%), relatives, a pedigree builder, and a review. They differ only in layout. Everything is saved in this browser. Nothing is sent anywhere.

Prototypes

  • Prototype A · StepperOne step per screen with Back, Next, and a progress bar.
  • Prototype B · AccordionOne page. Sections unlock in order, with a live summary. Best on tablet and desktop.
  • Prototype C · CardsMobile first. One question per card, big tap targets, Back and Next at the bottom.

Use it like an app

After the first visit everything works offline. On iPhone or iPad, tap Share, then Add to Home Screen. On Android or desktop Chrome, use Install in the browser menu.
